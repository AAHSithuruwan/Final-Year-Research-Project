# The Impact of Technical Documentation Quality on Software Maintenance Efficiency in Enterprise-Level Software Projects: An Empirical Analysis of Open-Source GitHub Repository Data

This repository contains the implementation and analysis conducted for the research **“The Impact of Technical Documentation Quality on Software Maintenance Efficiency in Enterprise-Level Software Projects: An Empirical Analysis of Open-Source GitHub Repository Data.”**

The research investigates the relationship between **technical documentation quality** and **software maintenance efficiency** in enterprise-level open-source software projects. The study uses secondary datasets and publicly available GitHub repository data.

Technical documentation quality is evaluated using **15 documentation quality metrics**, while software maintenance efficiency is evaluated using **issue closure rate, average issue resolution time, pull request merge rate, and average issue comment count**.

The final selected dataset contains **177 repositories**, with **162 valid repositories** used for statistical analysis. **Spearman correlation** and **simple linear regression** are used to evaluate the relationship between the two main research variables.

The repository contains the scripts and outputs related to:

- Dataset preparation and cleaning
- Enterprise-level project selection
- Documentation quality metric extraction
- GitHub maintenance metric collection
- Dataset integration
- Spearman correlation analysis
- Regression analysis
- Statistical result visualization

The findings showed a **very weak and statistically non-significant relationship** between technical documentation quality and software maintenance efficiency within the selected research context.
